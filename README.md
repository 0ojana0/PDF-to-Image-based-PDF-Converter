# PDF-to-Image-based-PDF-Converter
Convert text-based PDFs into photo-based PDFs for secured public sharing.

## Key Highlights of the Script
- Customization Settings at the Top
- Auto-Install Dependencies
- Automatically invokes the OS file dialog with multi-file selection enabled.
- Displays a progress window with dual progress bars (for overall files and individual pages) so the window never freezes during conversion.
- Opens the output folder automatically once conversion completes.
